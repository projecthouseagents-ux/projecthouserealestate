# Project House Agents
Web estática preparada para GitHub y Cloudflare Pages.

## Despliegue
1. Sube todos los archivos a un repositorio GitHub.
2. En Cloudflare: Workers & Pages → Create application → Pages → Connect to Git.
3. Selecciona el repositorio.
4. Framework preset: None.
5. Build command: vacío.
6. Build output directory: / (raíz).
7. Deploy.
